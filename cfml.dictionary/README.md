# cfml.dictionary

CFML syntax dictionaries for the Java 21 line (`21.0.0`). Each dictionary describes the tags and functions for a given CFML vendor and engine version.

```xml
<dependency>
    <groupId>com.github.cfmleditor</groupId>
    <artifactId>cfml.dictionary</artifactId>
    <version>21.0.0</version>
</dependency>
```
